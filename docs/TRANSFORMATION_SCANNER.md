# DART 변신기업 탐색기

## 목적

이 탐색기는 가격이나 단기 모멘텀을 스캔하지 않는다. 상장사가 인수·합병·사업목적 변경·설비투자·자금조달을 통해 **기존과 다른 경제적 실체로 바뀌기 시작하는 시점**을 OpenDART에서 찾는다.

성호전자형 사건의 핵심은 좋은 사업과 위험한 자본구조가 동시에 나타난다는 데 있다. 따라서 `좋은 공시/나쁜 공시`처럼 하나의 점수로 합치지 않는다.

1. `attention_score`: 회사의 경제적 성격이 달라지는 정도와 조사 우선순위
2. `financing_risk_score`: 차입·메자닌·유상증자·거버넌스 위험

고위험 후보를 낮은 종합점수로 숨기지 않는다. 위험이 클수록 자본구조를 더 빨리 확인해야 하기 때문이다.

## 처리 흐름

```text
OpenDART list.json
    ↓
공시명 taxonomy 분류
    ↓
주요사항보고서 구조화 API 보강
    ↓
선택적으로 document.xml 원문 ZIP 파싱
    ↓
동일 회사 30일 사건 클러스터링
    ↓
attention / financing risk 별도 점수화
    ↓
SQLite 중복 방지 + JSONL / Markdown 리포트
```

## 1. 공시 수집

`list.json`을 사용해 유가증권시장과 코스닥의 다음 공시유형을 조회한다.

- `B`: 주요사항보고
- `C`: 발행공시
- `E`: 기타공시
- `I`: 거래소공시

시장 전체 조회 기간 제한을 피하기 위해 긴 기간은 80일 단위로 자동 분할한다. 각 조각의 페이지를 끝까지 순회한 뒤 접수번호로 중복 제거한다.

기본 조회 기간은 전일부터 당일까지다.

## 2. 사건 taxonomy

| 분류 | 대표 공시 |
|---|---|
| `acquisition_control` | 타법인 주식 양수, 영업양수, 경영권 인수 |
| `merger_reorganization` | 합병, 분할, 주식교환·이전 |
| `portfolio_pivot` | 사업목적·정관 변경, 신규사업, 신규시설투자, 유형자산 양수 |
| `financing_dilution` | CB, BW, 유상증자, 차입·보증·담보 |
| `execution_validation` | 공급계약, 기술이전, 공동개발, 수주 |
| `governance_change` | 최대주주·대표이사·경영권 변경 |
| `divestiture` | 영업·자산·타법인 지분 양도 |

주주총회 소집공고는 제목만으로 후보화하지 않는다. `--include-documents`로 원문을 읽었을 때 사업목적 추가·신규사업 관련 문구가 실제로 확인돼야 점수가 생긴다.

## 3. 구조화 API 보강

현재 다음 OpenDART 주요사항보고서 API를 연결한다.

| 사건 | endpoint |
|---|---|
| 타법인 주식 및 출자증권 양수 | `otcprStkInvscrInhDecsn.json` |
| 전환사채 발행 | `cvbdIsDecsn.json` |
| 신주인수권부사채 발행 | `bdwtIsDecsn.json` |
| 유상증자 | `piicDecsn.json` |

접수일만 같다는 이유로 데이터를 붙이지 않는다. 공시 목록의 접수번호와 구조화 API 행의 접수번호가 정확히 일치할 때만 보강한다.

정정공시는 최초 공시가 더 이른 날짜에 있을 수 있으므로, 당일 조회에서 찾지 못하면 최대 400일 전까지 넓혀 동일 접수번호를 찾는다.

### 인수에서 추출하는 값

- 인수대상 회사·국가·주요사업
- 인수금액
- 총자산·자기자본 대비 비율
- 인수 후 지분율
- 인수 목적과 지급조건
- 경영권 확보 여부
- 차입·사채·인수금융 표현
- 풋옵션 등 추가 계약조건

### CB·BW에서 추출하는 값

- 발행금액, 회차, 만기와 금리
- 전환·행사가와 최저 조정가
- 잠재 신주 수와 공시상 희석률
- 영업양수·타법인 증권 취득·운영·채무상환 등 자금 사용 목적
- 사모·제3자배정 여부

### 유상증자에서 추출하는 값

- 보통주·우선주 신주 수
- 증자 전 주식 수
- 계산된 희석률
- 발행 방식과 자금 사용 목적

## 4. 원문 ZIP 파싱

`--include-documents`를 켜면 OpenDART `document.xml`에서 ZIP을 받아 XML·HTML 표를 파싱한다.

현재 원문 파서는 다음을 보조적으로 찾는다.

- 사업목적 추가
- 사업다각화
- 신규사업
- 신성장동력
- 정관변경
- 자산총계, 부채총계, 자본총계
- 매출액, 영업이익, 당기순이익

재무수치 추출은 표 문맥 전체를 이해한 값이 아니라 휴리스틱이다. 결과에 `document_financial_snapshot_is_heuristic=true`를 남기며, 원문 검증 없이 투자판단에 사용하면 안 된다.

## 5. 사건 클러스터

단일 공시보다 여러 공시의 연결이 더 중요하다. 같은 회사에서 기본 30일 안에 나타난 사건을 묶는다.

- 인수 + CB/BW/유상증자 → `leveraged_transformation`
- 인수 + 공급계약·수주 → `execution_confirmation`
- 확인된 사업전환 + 공급계약 → `pivot_confirmation`
- 인수 + 최대주주·대표 변경 → `governance_transition`
- 인수 + 사업범위 변경 → `portfolio_pivot_confirmation`

SQLite에 저장된 과거 사건과 현재 실행 중 먼저 처리된 사건을 모두 참조한다.

## 6. 점수 해석

### attention score

| 등급 | 점수 | 의미 |
|---|---:|---|
| `urgent` | 75 이상 | 당일 원문·인수대상·자본구조를 바로 조사할 후보 |
| `review` | 55~74.9 | 큰 변화 가능성이 있어 심층 검토할 후보 |
| `watch` | 35~54.9 | 단독으로는 부족하지만 후속 공시와 묶어 볼 후보 |
| `low` | 35 미만 | 기록은 남기되 즉시 조사할 필요가 낮음 |

주요 가점은 다음과 같다.

- 경영권·지배력 확보
- 회사 총자산·자기자본에 비해 큰 거래
- 신규사업·사업다각화 목적
- 인수와 자금조달의 결합
- 인수 뒤 공급계약·상업화 증거
- 원문에서 확인된 사업목적 변경

### financing risk score

주요 위험 신호는 다음과 같다.

- 총자산·자기자본 대비 과대한 인수
- 차입·사채·인수금융 지급조건
- CB·BW·유상증자의 잠재 희석률
- 채무상환 목적의 자금조달
- 사모·제3자배정 발행
- 인수와 자금조달이 짧은 기간 안에 결합된 경우
- 거버넌스 재편이 동시에 진행되는 경우

`attention_score - financing_risk_score`와 같은 종합점수는 만들지 않는다.

## 실행

```bash
python -m pip install -e ".[test]"
export DART_API_KEY="발급받은_인증키"

python -m transformation_scanner \
  --start 20251201 \
  --end 20251231 \
  --include-documents
```

주요 옵션:

```text
--corp-classes Y,K          시장 구분
--public-types B,C,E,I      공시유형
--min-band watch            리포트 최소 등급
--include-documents         원문 ZIP 파싱
--include-seen              처리한 접수번호 재평가
--no-persist                결과를 DB에 저장하지 않음
--no-state                  DB를 읽거나 쓰지 않음
--cluster-lookback-days 30  사건 결합 기간
--state-db PATH             SQLite 경로
--output-dir PATH           산출물 경로
```

## 산출물

```text
output/transformation_scanner/
├── state.sqlite3
├── 20251201_20251231_<time>_candidates.jsonl
└── 20251201_20251231_<time>_report.md
```

Markdown 리포트에는 다음이 포함된다.

- 회사·종목코드·DART 원문 링크
- 사건 분류와 접수일
- `attention_score`와 `financing_risk_score`
- 구조화된 핵심 사실
- 주목할 이유와 위험 이유
- 연관 접수번호와 사건 태그
- 구조화 API나 원문 파싱 실패 경고

## 현재 한계

1. 비상장 인수대상의 사업 질을 자동 평가하지 않는다.
2. 인수대상의 최근 3개년 재무제표를 문맥 인식해 추출하지 않는다.
3. 고객 집중도, 반복매출, 현금전환율, 자본집약도와 기술적 해자는 자동 검증 대상이 아니다.
4. 공시 이후 완전희석 주식 수와 point-in-time 시가총액을 자동 재구성하지 않는다.
5. 정정 전후 필드 변경을 자동 diff하지 않는다.
6. 점수는 연구 우선순위이며 매수·매도 신호가 아니다.
7. 실제 OpenDART 키를 이용한 역사 재생과 오탐률 측정은 별도 검증이 필요하다.
